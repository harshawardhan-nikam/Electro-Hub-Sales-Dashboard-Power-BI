# 📊 Electro Hub Sales Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Retail Sales Dashboard developed in Microsoft Power BI.

The dashboard transforms raw retail sales data into meaningful business insights using interactive visualizations, KPIs, slicers, and drill-down reports.

It enables business users to monitor sales performance, profitability, discounts, customer purchasing behavior, and product performance across multiple cities.

---

## 🎯 Business Problem

Retail businesses generate huge volumes of sales data every day.

Without proper visualization, it becomes difficult to answer questions like:

- Which products generate maximum revenue?
- Which products are underperforming?
- Which cities contribute the highest sales?
- How do discounts affect profitability?
- What are monthly and yearly sales trends?
- How does profit change over time?

This dashboard answers all these questions interactively.
